    First run? Set up the runner

source .venv/bin/activate

    Enable one-click runs

    Start the local launcher once from the repository root, then use the page it opens.

    python -m leaderboard.serve

    A file preview can show scripts, but cannot open Terminal on its own.

    Runs are sequential and stop on a failed command. Commit source changes first. Terminal prompts for missing service credentials with input hidden.

    How a run works.

    8workloads / database
    3tries each
    1. 01
      Prepare & load

      Create a temporary database and load the shared dataset.

    2. 02
      Measure

      Time branch, read, and write workloads with identical settings.

    3. 03
      Clean up & save

      Remove run resources and save timings and run details as JSON.

    4. 04
      Validate & compare

      Check the result files and rebuild the leaderboard’s data.

    How results reach the leaderboard

    The runner saves a JSON result for each database: timing attempts, load and setup times, and environment details. The validator checks it; the build generates data.js, which index.html reads to display the rankings.

    Results currently stay on your machine. Future official rankings will use standardized benchmark workers, with server-side validation and publishing. Local runs remain for development; cloud execution isn’t implemented yet.
