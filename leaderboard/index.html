    How workflows are timed and judged
    Completion time
    Starts once the schema and seed data are in place. Stops when the last workflow step has finished and any background traffic has stopped. Setup and database cleanup are recorded separately.
    On the board
    A run starts only after validation: committed sources, all six workflows, a runnable system and a free port. A finished run is shown only if it also validates: sources unchanged, server stopped, every database cleaned up and every attempt's evidence readable. Anything else is listed below the board with its reason.
    Rank
    By one workflow's completion time at a time, among systems run with the same workload, benchmark revision, runtime and machine. Tied times share a rank. There is no overall score.
    Shading
    A darker cell is closer to the fastest time in its column; the check marks the fastest.

      How scores work
      First query
      Time to first query on a new branch.

      Geometric mean of the ticked workloads' ratios. At least one workload is always counted, and the column header names the count.
      Load
      Load time only; provisioning is excluded.
      Best repeat
      The faster of tries 2 and 3; both must succeed.
